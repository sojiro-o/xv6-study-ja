# xv6-riscv 日本語教材・実験環境

MIT PDOS の教育用 OS である RISC-V 版 [xv6 (`xv6-riscv`)](https://github.com/mit-pdos/xv6-riscv) を、**動くコードと1対1で対応させながら日本語で読み解く**ための教材と実験環境です。

C 言語を少し書いたことがあれば読み進められるよう、直訳調ではなく一から書き下ろしています。ポインタ・構造体・レジスタなどの前提知識も、必要になったその場で補足します。

- **対象 xv6 コミット**: [`e93dabeb98431235c6e1a101cb96c73c923fdbc4`](https://github.com/mit-pdos/xv6-riscv/tree/e93dabeb98431235c6e1a101cb96c73c923fdbc4)（リポジトリ直下の `VERSIONS.md` に記録）

## このリポジトリの使い方

1. **環境を用意して動かす**  
   GitHub Codespaces、VS Code Dev Containers、または WSL2 Ubuntu でリポジトリを開き、まずはスモークテストと起動を試します。詳しい手順は [xv6 実験環境ガイド](env.md) にまとめています。
   ```sh
   ./scripts/test smoke   # 自動ビルド＆動作確認
   ./scripts/run          # xv6 を対話起動（終了は Ctrl-a → x）
   ```

2. **章を読みながら実際のコードを追う**  
   各章に掲載されているコード抜粋は、手元の `xv6-riscv/` からビルド時に自動抽出されたものです。各抜粋のリンクから、固定コミットの上流 GitHub コードも直接開けます。

3. **小さな改造と確認問題で手を動かす**  
   各章の後半には、`./scripts/exp <名前>` で実験ブランチを切って試せる小さな改造実験と確認問題があります。改造実験は `./scripts/check-lab <名前>` で自動検証することもできます。

4. **AI エージェントを「家庭教師」として使う（任意）**  
   リポジトリ直下の `GEMINI.md` と `AGENTS.md` には、学習サポート用のルールが設定されています。Gemini CLI などのエージェントに質問すると、最初に次の3つのモードを選べます。
   - **解説のみ**: コードを書き換えず、仕組みや関数の動きを噛み砕いて説明します。
   - **ヒント**: コードを書き換えず、着目すべき関数や考え方だけを示します。
   - **実装込み**: 実験ブランチ上でコード変更・テスト実行まで一緒に行います。
